Questions & Answers

Frequently Asked Questions

Why does YouTube stream 8-bit even on my 10-bit monitor? ▼

Web browsers like Chrome and Edge check Windows HDR status. When Windows is in SDR mode (even with a 10-bit monitor), browsers report to YouTube that only standard 8-bit SDR is supported. YouTube then deliberately serves Profile 0 8-bit VP9. TenBit Display Overlay bypasses the browser entirely to request true 10-bit VP9 Profile 2 streams.

Does this work on 8-bit + FRC monitors? ▼

Yes! 8-bit + FRC (Frame Rate Control) monitors are designed to accept a 10-bit input signal and rapidly cycle sub-pixels to produce all 1.07 billion colors. TenBit Display Overlay sends the full 10-bit signal across the cable so your monitor's internal FRC engine can perform at its peak.

Do I need administrator privileges or installation? ▼

No installation is required. TenBit Display Overlay is packaged as a completely standalone, self-contained Windows executable. You can run it directly from your Desktop or USB drive without modifying Windows system files.

Does the overlay impact gaming or GPU performance? ▼

Zero impact. The overlay uses efficient lightweight Direct3D 11 rendering with hardware swapchains. CPU usage remains under 0.1% and GPU usage is negligible.
